Privacy Policy — Biopalm Automation

Last updated: 16 October 2026

Who we are

Biopalm Automation is an internal tool operated by Biopalm Education for its own staff. Contact: mkt.biopalm@gmail.com.

What data the tool accesses

When a Biopalm staff account authorizes the tool, it accesses only that account's data needed for the tasks below, using Google APIs:

  • Google Drive: class-recording video files in Biopalm's own folders (to copy them and to read them for upload), and small file labels used to avoid duplicate work.
  • YouTube (YouTube API Services): Biopalm's own channel, videos and playlists (to upload class recordings as private videos and add them to a private playlist).
  • Google Forms: forms and responses owned by Biopalm.

How the data is used and shared

  • Data is used only to perform the tasks above for Biopalm. It is not sold, not used for advertising, and not shared with anyone outside Biopalm.
  • Videos are uploaded as private. They are visible only to Biopalm's own channel account.
  • The tool runs on service providers that process data on Biopalm's behalf: Google (Drive, YouTube), GitHub Actions and Composio. Video files pass through these services only while a task is running and are not kept by the tool afterwards.
  • Access tokens are stored as encrypted secrets and are used only by the tool.

YouTube

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google Account → Third-party connections, or for YouTube via the Google security settings page. To request deletion of any stored data, email us.
